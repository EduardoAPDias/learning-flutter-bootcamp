# Flutter Bootcamp — Dart & Flutter

![Flutter](https://img.shields.io/badge/Flutter-02569B?style=flat&logo=flutter&logoColor=white)
![Dart](https://img.shields.io/badge/Dart-0175C2?style=flat&logo=dart&logoColor=white)

Projetos práticos desenvolvidos durante o curso **The Complete Flutter Development Bootcamp with Dart**, cobrindo desde widgets e layouts até lógica de aplicação, gerenciamento de estado e integração de pacotes externos.

## Projetos

| Projeto | Descrição | Conceitos |
|---|---|---|
| Mi Card | Cartão de visitas pessoal | Stateless Widgets, Row/Column, Assets |
| Dicee | Simulador de dados aleatórios | Stateful Widgets, Gestos, Lógica Dart |
| Magic 8-Ball | App de tomada de decisão | Manipulação de estado, Interatividade |
| Xylophone | Instrumento musical interativo | Pacotes externos, audioplayers |
| Quizzler | App de quiz interativo | Classes, OOP, Widgets customizados |
| Destini | Jogo de história interativa | Lógica de ramificação, Estado |
| BMI Calculator | Calculadora de IMC | Widgets customizados, Enums, OOP |

## Como usar

```bash
git clone https://github.com/EduardoAPDias/flutter-bootcamp
cd nome-do-projeto
flutter pub get
flutter run
```
